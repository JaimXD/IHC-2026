# Flujo: Crear ítem en Sprint Backlog (start → finish)

Tarea: Añadir un ítem al backlog del sprint.

Precondiciones: Sprint seleccionado.

Pasos (capturas):
1. Start — Dashboard → Sprint Backlog (`..._step01_backlog_dashboard.png`)
2. Click "Agregar ítem" (`..._step02_open_form.png`)
3. Completar título, vincular historia, estimación (`..._step03_fill_fields.png`)
4. Asignar responsable (`..._step04_assign.png`)
5. Guardar (`..._step05_submit.png`)
6. Finish — Ítem visible en backlog (`..._step06_confirmation_and_list.png`)

Evidencias: DOM inspector, keyboard focus, manifest row.
