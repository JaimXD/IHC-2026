# Flujo: Añadir observación a prueba (start → finish)

Tarea: Añadir una observación dentro del detalle de una prueba.

Precondiciones: Prueba existente; usuario autenticado.

Pasos (capturas):
1. Start — Ir al detalle de la prueba (`..._step01_open_test_detail.png`)
2. Click "Añadir observación" (`..._step02_open_observation_form.png`)
3. Escribir texto y tags (`..._step03_fill_text_tags.png`)
4. Adjuntar archivo (si aplica) (`..._step04_attach_file.png`)
5. Guardar (`..._step05_submit.png`)
6. Finish — Observación visible en lista (`..._step06_confirmation_and_list.png`)

Evidencias: captura del form, network request, DOM inspector del textarea y botones.
