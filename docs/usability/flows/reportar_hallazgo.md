# Flujo: Reportar hallazgo (start → finish)

Tarea: Crear un hallazgo con severidad y evidencia.

Precondiciones: Usuario autenticado.

Pasos (capturas):
1. Start — Dashboard → Hallazgos (`..._step01_hallazgos_dashboard.png`)
2. Click "Nuevo hallazgo" (`..._step02_open_form.png`)
3. Completar campos (tipo, severidad, descripción) (`..._step03_fill_fields.png`)
4. Subir evidencia (imagen) (`..._step04_upload_evidence.png`)
5. Guardar (`..._step05_submit.png`)
6. Finish — Hallazgo en lista con evidencia (`..._step06_confirmation_and_list.png`)

Evidencias: preview de la imagen subida, request en Network, DOM inspector.
