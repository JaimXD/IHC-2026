# Flujo: Crear tarea (start → finish)

Tarea: Crear una nueva tarea y asignarla.

Precondiciones: Usuario autenticado; proyecto/sprint seleccionado.

Pasos (capturas):
1. Start — Dashboard → Tareas (`..._step01_tareas_dashboard.png`)
2. Click "Nueva tarea" (`..._step02_form_empty.png`)
3. Rellenar título y asignar participante (`..._step03_fill_title_assign.png`)
4. Estimar y seleccionar prioridad (`..._step04_estimate_priority.png`)
5. Guardar (`..._step05_submit.png`)
6. Finish — Ver tarea en lista/kanban (`..._step06_confirmation_and_list.png`)

Evidencias: DOM inspector, keyboard focus, manifest row con tiempo.
