# WCAG checklist mínima (Nivel AA recomendado)

Marcar cada ítem con: `OK` / `NO` / `N/A` y proporcionar evidencia (archivo).

- [ ] Texto: contraste suficiente (≥ 4.5:1) — evidencia: `..._contrast_before.png`, `..._contrast_after.png`
- [ ] Imágenes: `alt` presentes para imágenes informativas
- [ ] Formularios: `label` visible y ligado a input
- [ ] Focus: indicador de foco visible en todos los controles interactivos
- [ ] Keyboard: todos los flujos principales completables con teclado
- [ ] ARIA: roles y `aria-*` en widgets complejos
- [ ] Timeouts: avisos si hay límites de tiempo
- [ ] Estructura semántica: encabezados y landmarks
- [ ] Error recovery: mensajes claros y sugerencias

Registrar cada resultado en `manifest.csv` y crear issues para violaciones.
