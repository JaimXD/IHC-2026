# HU-01: Registrar Participante

**Flujo Asociado:** T-01
**Prioridad:** Alta 🔴

> **Historia de Usuario:** Como gestor de pruebas, quiero añadir un participante con nombre y correo electrónico para asignarlo a las evaluaciones de usabilidad[cite: 1].

## Criterios de Aceptación (ISO 9241-11)

*   **Efectividad:** El sistema debe registrar al participante exitosamente; si el correo es inválido, debe mostrar un mensaje de error y bloquear la acción[cite: 1].
*   **Eficiencia:** El formulario debe ser completable utilizando únicamente la navegación por teclado con el indicador de foco visible[cite: 1].
*   **Satisfacción:** Tras el registro, el sistema debe mostrar una confirmación visual de "Participante creado" para informar al usuario[cite: 1].
