# HU-02: Crear Prueba

**Flujo Asociado:** T-02
**Prioridad:** Alta 🔴

> **Historia de Usuario:** Como evaluador, quiero crear una nueva prueba definiendo título, fecha y participantes para estructurar la sesión[cite: 1].

## Criterios de Aceptación (ISO 9241-11)

*   **Efectividad:** El sistema debe impedir la creación de la prueba si existen campos obligatorios vacíos, mostrando los errores correspondientes[cite: 1].
*   **Eficiencia:** El formulario debe incluir atributos y roles ARIA para garantizar el correcto uso con herramientas de accesibilidad[cite: 1].
*   **Satisfacción:** El botón de acción debe incluir un indicador de carga (loader) para informar del estado del sistema mientras se procesa la petición[cite: 1].
