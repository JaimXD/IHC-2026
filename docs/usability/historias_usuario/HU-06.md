# HU-06: Crear ítem en Sprint Backlog

**Flujo Asociado:** T-06
**Prioridad:** Media 🟡

> **Historia de Usuario:** Como administrador, quiero agregar un ítem al backlog del sprint activo para planificar su resolución[cite: 1].

## Criterios de Aceptación (ISO 9241-11)

*   **Efectividad:** El ítem debe vincularse al hallazgo reportado y añadirse a la cola del sprint correctamente[cite: 1].
*   **Eficiencia:** La acción debe requerir un mínimo de interacciones para no interrumpir el flujo de reporte del evaluador[cite: 1].
*   **Satisfacción:** El estado del backlog debe visualizarse de forma clara para confirmar que el ítem fue encolado[cite: 1].
