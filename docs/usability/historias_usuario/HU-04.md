# HU-04: Añadir Observación

**Flujo Asociado:** T-04
**Prioridad:** Media 🟡

> **Historia de Usuario:** Como evaluador, quiero registrar una observación dentro del detalle de una prueba existente para documentar el progreso[cite: 1].

## Criterios de Aceptación (ISO 9241-11)

*   **Efectividad:** El sistema debe vincular la observación directamente a la tarea y al participante correcto sin pérdida de datos[cite: 1].
*   **Eficiencia:** El área de texto (textarea) debe ser fácilmente navegable y operable para un ingreso rápido de información en vivo[cite: 1].
*   **Satisfacción:** Tras añadir la observación, debe aparecer en la lista de la prueba indicando claramente si el estatus fue Fallido o Exitoso[cite: 1].
