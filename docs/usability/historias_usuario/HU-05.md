# HU-05: Reportar Hallazgo

**Flujo Asociado:** T-05
**Prioridad:** Alta 🔴

> **Historia de Usuario:** Como analista UX, quiero crear un hallazgo con tipo, severidad, descripción y evidencia adjunta para reportar los problemas encontrados[cite: 1].

## Criterios de Aceptación (ISO 9241-11)

*   **Efectividad:** El hallazgo debe guardarse conservando los datos de la recomendación de mejora y el nivel de severidad asignado[cite: 1].
*   **Eficiencia:** El formulario debe permitir categorizar el hallazgo rápidamente mediante listas desplegables[cite: 1].
*   **Satisfacción:** El sistema debe proporcionar una vista previa de la imagen de evidencia cargada antes de confirmar el guardado[cite: 1].
