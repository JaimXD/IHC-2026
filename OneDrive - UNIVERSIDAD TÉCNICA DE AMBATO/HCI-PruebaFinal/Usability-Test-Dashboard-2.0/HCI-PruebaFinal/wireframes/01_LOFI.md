# WIREFRAME LO-FI (Baja Fidelidad)

## Dashboard - Estructura Básica

```
┌────────────────────────────────────────────────┐
│ LOGO    TÍTULO         [Menu] [Profile] [Exit] │
├────────────────────────────────────────────────┤
│                                                │
│  [Sidebar]                    [Main Content]   │
│  • Dashboard        ┌──────────────────────┐   │
│  • Hallazgos        │ Breadcrumb           │   │
│  • Observaciones    │ Home > Dashboard     │   │
│  • Participantes    └──────────────────────┘   │
│  • Tareas           ┌──────────────────────┐   │
│  • Plan             │  TITULO              │   │
│                     │  Descripción         │   │
│                     └──────────────────────┘   │
│                                                │
│                     ┌────┐ ┌────┐ ┌────┐      │
│                     │Tar1│ │Tar2│ │Tar3│      │
│                     └────┘ └────┘ └────┘      │
│                                                │
│                     ┌────┐ ┌────┐ ┌────┐      │
│                     │Tar4│ │Tar5│ │Tar6│      │
│                     └────┘ └────┘ └────┘      │
│                                                │
└────────────────────────────────────────────────┘
```

## Formulario - Estructura Lo-Fi

```
┌────────────────────────────────────────────┐
│ Breadcrumb: Home > Formulario              │
├────────────────────────────────────────────┤
│                                            │
│  NOMBRE DEL FORMULARIO                     │
│                                            │
│  [Nombre:        ______________]  *        │
│  [Email:         ______________]  *        │
│  [Teléfono:      ______________]           │
│  [Departamento:  ▼____________]  *         │
│                                            │
│  [GUARDAR]  [LIMPIAR]  [CANCELAR]         │
│                                            │
└────────────────────────────────────────────┘
```

## Características Lo-Fi

- ✓ Grid básico 12 columnas
- ✓ Breadcrumb en posición superior
- ✓ Sidebar izquierdo de navegación
- ✓ Campos claramente identificados
- ✓ Asteriscos (*) para campos requeridos
- ✓ Botones diferenciados (Primario, Secundario, Terciario)
- ✓ Estructura simple sin colores
